# LeadFlow

## Objetivo

Sistema de prospecção comercial e CRM desenvolvido para otimizar o processo comercial da OVNI Productions.

---

# Tecnologias

## Backend

- Django
- Django REST Framework
- PostgreSQL

## Frontend

- Next.js
- React
- TypeScript
- TailwindCSS
- Shadcn/UI

# Módulos

- IA
- Automações
